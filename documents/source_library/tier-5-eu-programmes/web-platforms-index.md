# Tier 5 - EU Programmes: Web Platforms Index

These Tier 5 sources are interactive web platforms that cannot be downloaded as static files.
They should be consulted directly via their URLs when needed.

## Platforms

### NetZeroCities Platform
- **URL**: https://netzerocities.eu/
- **Description**: Main portal for the EU Mission "100 Climate-Neutral and Smart Cities by 2030". Contains news, programme information, city profiles, and Climate City Contract (CCC) resources.
- **Key subpage**: https://netzerocities.eu/climate-city-contract/ - Overview of the CCC framework
- **Key subpage**: https://netzerocities.eu/mission-cities/ - List of mission cities (includes Aachen, Dresden, Heidelberg, Klagenfurt, Leipzig, Mannheim, Munich, Munster)
- **Note**: City-specific CCC documents are not publicly downloadable; they are hosted within the authenticated app.

### NetZeroCities App (Knowledge Repository)
- **URL**: https://netzerocities.app/
- **Description**: Authenticated platform with CCC tools, city profiles, and knowledge resources. Requires login.
- **Key subpage**: https://netzerocities.app/knowledge-ccc - CCC knowledge base (requires auth)
- **Note**: No public access to city-specific CCC PDFs. All content is behind authentication.

### EU SUMP Database
- **URL**: https://urban-mobility-observatory.transport.ec.europa.eu/sustainable-urban-mobility-plans/eu-city-database-sumps_en
- **Description**: European Commission database of Sustainable Urban Mobility Plans (SUMPs). Searchable by city/country with plan details and links.

### MobiData BW
- **URL**: https://mobidata-bw.de/
- **Description**: Open mobility data platform for Baden-Wurttemberg, Germany. Provides transport data, APIs, and mobility analytics.

### Open Data Sachsen
- **URL**: https://www.opendata.sachsen.de/
- **Description**: Open data portal for the German state of Saxony. Relevant for Dresden and Leipzig data (both are in Saxony).

### GovData
- **URL**: https://www.govdata.de/
- **Description**: Germany's central open data portal aggregating datasets from federal, state, and municipal governments. Searchable for climate, transport, energy, and urban planning data.
